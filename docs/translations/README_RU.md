## Обзор Проекта

Оригинальная высокопроизводительная прошивка для микроконтроллеров **Raspberry Pi RP2040 (Raspberry Pi Pico, Pico W и Waveshare RP2040-Zero)** с архитектурой **100% прямого подключения через USB-кабель (Ethernet over USB: RNDIS / CDC-ECM)**.

Разработана специально для профессиональной передачи сигналов сценического освещения DMX512 по сети Art-Net UDP (Порт 6454), обрабатывая от **1 до 8 одновременных потоков (юниверсов) DMX** (до 4096 каналов) параллельно на фиксированной частоте 44 Гц без джиттера.

---

## Сетевая архитектура USB Ethernet (Plug-and-Play)

При подключении к любому компьютеру по обычному USB-кабелю RP2040 определяется как **высокоскоростной виртуальный сетевой адаптер Ethernet**:
- **Windows:** Встроенный драйвер Remote NDIS (**RNDIS**) через дескрипторы Microsoft OS 1.0 — моментальное распознавание без установки драйверов.
- **macOS / Linux:** Нативный драйвер **CDC-ECM**.
- **Встроенный сервер DHCP:** Автоматическая выдача IP-адреса компьютеру в той же подсети, исключая ручную настройку.

### Режимы работы и безопасные диапазоны IP

Для предотвращения конфликтов с Wi-Fi или корпоративными сетями (`192.168.x.x`):

1. **Режим первоначальной настройки (Setup Wizard):**
   - **IP:** `10.10.0.1` (компьютер получает `10.10.0.2`).
   - Автоматически активируется при первом включении или после сброса к заводским настройкам для выбора номера узла, числа активных выходов (1-8), имени, языка, темы и частоты DMX.

2. **Рабочий многоузловой режим (Art-Net активен):**
   - **IP:** `2.0.N.1` (где `N` — номер узла от 1 до 16).
   - Поддержка до **16 узлов одновременно** на одном компьютере или USB-концентраторе (128 юниверсов / 65 536 каналов DMX):
     - **Узел 1:** IP `2.0.1.1` -> Юниверсы 0–7
     - **Узел 2:** IP `2.0.2.1` -> Юниверсы 8–15
     - **Узел 3:** IP `2.0.3.1` -> Юниверсы 16–23
     - *(настраивается до Узла 16: IP `2.0.16.1` -> Юниверсы 120–127)*

## Полная многоязычность (8 языков)

Прошивка поддерживает: Португальский [PT], Английский [EN], Испанский [ES], Французский [FR], Немецкий [DE], Итальянский [IT], Русский [RU] и Китайский [ZH]. Выбор языка мгновенно применяется на всех веб-страницах и на дисплее OLED I2C, сохраняясь во внутренней Flash-памяти SPI.

## Преимущества производительности Bare-Metal C SDK

1. **Реальное двухъядерное разделение (Dual-Core):**
   - **CORE 0:** Обработка стека TinyUSB, lwIP TCP/IP, веб-сервера HTTP (Порт 80), приемника UDP Art-Net (Порт 6454), вывод на экран OLED SSD1306 и аппаратный таймер Watchdog.
   - **CORE 1:** Выделенный непрерывный генератор DMX512 с наивысшим приоритетом. Формирует фреймы DMX без задержек и джиттера, изолированно от сетевого трафика.

2. **Аппаратный генератор DMX512 (8 автоматов состояний PIO + DMA):**
   - Использует оба блока PIO (PIO0 и PIO1) на 8 параллельных State Machines.
   - Точные импульсы BREAK (140 мкс) и MAB (16 мкс) формируются аппаратно на скорости 250 кбод (8N2).
   - Непрерывный синхронный вывод до 8 юниверсов на частоте 44 Гц.

3. **Атомарный двойной буфер Ping-Pong и ArtSync:**
   - Мгновенное атомарное переключение буферов предотвращает визуальные разрывы (tearing).
   - Полная поддержка пакетов ArtSync (OpSync) для синхронного обновления всех юниверсов.

## Назначение выводов платы (Pinout)

Удобное, последовательное и надежное распределение:

| Функция | Вывод GPIO | Вывод платы (Pico) | Интерфейс / Шина | Примечание |
| :--- | :--- | :--- | :--- | :--- |
| **DMX Выход 1** | **GP0** | Вывод 1 | PIO0 - SM 0 | Начальный юниверс + 0 |
| **DMX Выход 2** | **GP1** | Вывод 2 | PIO0 - SM 1 | Начальный юниверс + 1 |
| **DMX Выход 3** | **GP2** | Вывод 4 | PIO0 - SM 2 | Начальный юниверс + 2 |
| **DMX Выход 4** | **GP3** | Вывод 5 | PIO0 - SM 3 | Начальный юниверс + 3 |
| **DMX Выход 5** | **GP4** | Вывод 6 | PIO1 - SM 0 | Начальный юниверс + 4 |
| **DMX Выход 6** | **GP5** | Вывод 7 | PIO1 - SM 1 | Начальный юниверс + 5 |
| **DMX Выход 7** | **GP6** | Вывод 9 | PIO1 - SM 2 | Начальный юниверс + 6 |
| **DMX Выход 8** | **GP7** | Вывод 10 | PIO1 - SM 3 | Начальный юниверс + 7 |
| **OLED SDA** | **GP8** | Вывод 11 | I2C0 SDA (400 кГц) | Экран SSD1306 128x64 |
| **OLED SCL** | **GP9** | Вывод 12 | I2C0 SCL (400 кГц) | Экран SSD1306 128x64 |
| **LED DMX Ext** | **GP10** | Вывод 14 | Цифровой выход | Внешний индикатор DMX |
| **Встроенный LED**| **GP25** | LED платы | Цифровой выход | Дублирует GP10 |

*Неиспользуемые выводы DMX переводятся программно в высокоимпедансное состояние (High-Z).*

## Подключение трансиверов RS-485 (MAX485 / SN75176)

Для каждого выхода DMX (GP0–GP7):
- **DI (Data In):** К соответствующему выводу GPIO RP2040.
- **DE + RE:** Соединить вместе и подключить к `3V3` (постоянная передача).
- **VCC:** К питанию `5V` (VBUS кабеля USB).
- **GND:** К общему проводу схемы (`GND`).
- **A (+):** Прямая линия DMX (Контакт XLR 3).
- **B (-):** Инверсная линия DMX (Контакт XLR 2).
- **XLR Контакт 1:** Экран / Земля (GND).

## Готовый файл прошивки (.UF2)

Доступен в:
- **`binarios_finais/artnet_dmx.uf2`** (или в разделе [GitHub Releases](https://github.com/Matheus-devpixel/PicoArtNetDMXNode/releases))

### Прошивка в Raspberry Pi RP2040:
1. Зажмите кнопку **BOOTSEL** на плате Pico.
2. Подключите кабель USB к компьютеру и отпустите кнопку. Появится съемный накопитель `RPI-RP2`.
3. Перетащите файл `artnet_dmx.uf2` на диск `RPI-RP2`.
4. Плата сразу перезагрузится и станет доступна как сетевая карта по адресу `10.10.0.1` или `2.0.N.1`.

## Программа тестирования передачи (ArtNet_Test.py)

В репозиторий включен высокоточный скрипт тестирования на Python ([`ArtNet_Test.py`](../../ArtNet_Test.py)), передающий до 4096 каналов DMX (8 юниверсов) со скоростью 60 FPS без джиттера:

```bash
# Стандартная симуляция световых приборов (вращающиеся головы, RGB-прожекторы, стробоскопы)
python ArtNet_Test.py

# Настройка целевого IP и частоты кадров (например, 60 FPS на 2.0.1.1)
python ArtNet_Test.py 60 2.0.1.1

# Синхронный стробоскоп по всем 4096 каналам
python ArtNet_Test.py --ip=2.0.1.1 --mode=strobe

# Плавный градиент цветового круга RGB
python ArtNet_Test.py --ip=2.0.1.1 --mode=rgb
```
